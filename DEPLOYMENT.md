# Развертывание

## Render

`render.yaml` настраивает один экземпляр бота и постоянный диск `/var/data` для SQLite. Для диска используется платный план Render Starter; проверьте текущую стоимость в Render перед созданием сервиса. Не запускайте несколько экземпляров с одним набором bot token: polling одного токена должен работать только в одном процессе.

Задайте в Render секреты `API_ID`, `API_HASH`, `BOT_TOKEN`, `ADMIN_ID` и `CLONE_TOKEN_ENCRYPTION_KEY`. Остальные параметры уже описаны в `render.yaml`. Ключ шифрования можно сгенерировать после установки зависимостей:

```sh
python -c 'from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())'
```

Храните ключ отдельно от исходников и резервной копии базы. Не меняйте и не теряйте его: без исходного ключа токены сохранённых клонов восстановить нельзя. Не удаляйте постоянный диск, если нужно сохранить пользователей, платежи, сессии и зарегистрированные копии.

## Продажа клонов

В основном боте владелец открывает `/admin` → «Klonlar va Stars narxi», задаёт цену и просматривает подключённые копии. Покупатель оплачивает инвойс Telegram Stars в основном боте, создаёт отдельного бота через @BotFather и отправляет его токен. После проверки токена копия начинает работать; пользователи и пользовательские сессии хранятся в общей базе.

Stars за инвойсы зачисляются на баланс основного бота в Telegram. Это не перевод непосредственно на личный Stars-баланс владельца; вывод средств зависит от правил Telegram.
